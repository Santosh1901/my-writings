I spend more time reading the diff

Be honest. How much of your actual coding time is now spent reviewing what the agent wrote versus writing it yourself. Mine keeps climbing.

Using AI to write code is easy. Using it without becoming the intern who cant read the diff. That is the skill. I posted that and then sat with it because it was also about me.

Everyone talks about the model. Almost nobody talks about the harness. After 40 steps the thing goes off the rails and you are just there cleaning. Charts dont debug my repo.

What I do now

  • I explain the approach first.
  • Then I let it implement.
  • Then I break it on purpose.
  • If step 3 scares you, you are already dependent.

People are trying to skip straight to coding agents. If you dont understand the tradeoffs you just end up vibe-coding bad decisions faster. Software engineering fundamentals. That part is still the job. The rest is just speed.

I am still figuring this out. Some days I feel faster. Some days I just reviewed 400 lines I would have written in 80.
